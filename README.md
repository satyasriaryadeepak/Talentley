# Talentley School Management System

Talentley is a premium, all-in-one platform designed for schools to manage students, conduct national-level talent exams, and showcase academic excellence through dynamic leaderboards.

## 🚀 Features
- **Unified Login**: Smart detection for Admin and Student accounts.
- **Academic Network**: Manage exams, syllabus, and question banks.
- **Leaderboard Control**: Curated and automatic "Hall of Fame" for top achievers.
- **Premium UI**: Modern, glassmorphic design built with Next.js and Framer Motion.

## 🛠 Tech Stack
- **Frontend**: Next.js, TypeScript, Tailwind CSS, Framer Motion.
- **Backend**: Node.js, Express, Sequelize (SQL).
- **Database**: PostgreSQL / SQLite (Development).

## 📥 Installation

### 1. Clone the repository
```bash
git clone https://github.com/talentleyschool-ops/talentley.git
```

### 2. Setup Backend
```bash
cd backend
npm install
npm run dev
```

### 3. Setup Frontend
```bash
cd ../frontend
npm install
npm run dev
```
